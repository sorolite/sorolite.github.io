Problem 1

Find the tangent plane to z=x2+y2z=x^2+y^2 at (1,2,5)(1,2,5).

Reveal solution

We first find each partial derivative of zz.

We find ∂z/∂x\partial z / \partial x by treating yy as a constant: ∂z/∂x=2x\partial z / \partial x = 2x. At the point (x0,y0,z0)=(1,2,5)\left( x_0 , y_0 , z_0 \right) = (1,2,5), this becomes ∂z/∂x=2x0=2(1)=2\partial z / \partial x = 2 x_0 = 2(1) = 2.

We next find ∂z/∂y\partial z / \partial y by treating xx as a constant: ∂z/∂y=2y\partial z / \partial y = 2y. At the point (x0,y0,z0)=(1,2,5)\left( x_0 , y_0 , z_0 \right) = (1,2,5), this becomes ∂z/∂y=2y0=2(2)=4\partial z / \partial y = 2 y_0 = 2(2) = 4.

The equation for the tangent plane at the point (x0,y0,z0)\left( x_0 , y_0 , z_0 \right) is z=z0+(∂z/∂x)(x−x0)+(∂z/∂y)(y−y0)z = z_0 + \left( \partial z / \partial x \right) \left( x - x_0 \right) + \left( \partial z / \partial y \right) \left( y - y_0 \right). Here, this gives z=5+2(x−1)+4(y−2)z = 5 + 2 (x-1) + 4(y-2), or 2x+4y−z−5=02x + 4y - z -5 = 0.

Problem 2

Find the tangent plane to z=xyz=xy at (2,3,6)(2,3,6).

Reveal solution

We first find each partial derivative of zz.

We find ∂z/∂x\partial z / \partial x by treating yy as a constant: ∂z/∂x=y\partial z / \partial x = y. At the point (x0,y0,z0)=(2,3,6)\left( x_0 , y_0 , z_0 \right) = (2, 3, 6), this becomes ∂z/∂x=y0=3\partial z / \partial x = y_0 = 3.

We next find ∂z/∂y\partial z / \partial y by treating xx as a constant: ∂z/∂y=x\partial z / \partial y = x. At the point (x0,y0,z0)=(2,3,6)\left( x_0 , y_0 , z_0 \right) = (2, 3, 6), this becomes ∂z/∂y=x0=2\partial z / \partial y = x_0 = 2.

The equation for the tangent plane at the point (x0,y0,z0)\left( x_0 , y_0 , z_0 \right) is z=z0+(∂z/∂x)(x−x0)+(∂z/∂y)(y−y0)z = z_0 + \left( \partial z / \partial x \right) \left( x - x_0 \right) + \left( \partial z / \partial y \right) \left( y - y_0 \right). Here, this gives z=6+3(x−2)+2(y−3)z = 6 + 3 (x-2) + 2(y-3), or 3x+2y−z−6=03x + 2y - z -6 =0.
