Vector fields

Work, circulation, flux, and path independence.

Problem 1

Determine whether F=⟨2xy,x2+3y2⟩ is conservative on R2, and find a potential if it is.

Reveal solution

Py=2x=Qx, so the field is conservative. Integrating P in x gives φ=x2y+g(y). Matching φy yields g′=3y2. Thus φ=x2y+y3+C.

Problem 2

Evaluate ∫CF·dr for F=⟨y,x⟩ along the line from (0,0) to (2,1).

Reveal solution

A potential is φ=xy. By the fundamental theorem for line integrals, the value is φ(2,1)−φ(0,0)=2.

Problem 3

Use Green’s theorem to find the counterclockwise circulation of F=⟨−y,x⟩ around the unit circle.

Reveal solution

The scalar curl is Qx−Py=1−(−1)=2. Therefore circulation equals twice the unit disk’s area: 2π.

Problem 4

Find the outward flux of F=⟨x,y,z⟩ through the unit sphere.

Reveal solution

By the divergence theorem, ∇·F=3. Hence the flux is 3 times the unit ball’s volume: 3(4π3)=4π.
